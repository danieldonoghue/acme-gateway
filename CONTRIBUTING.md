# Contributing

Contributions are welcome in the form of pull requests.

## Before you start

For anything beyond a small bug fix or typo, please open a discussion first by starting a conversation in a PR or reaching out via GitHub. This avoids duplicate effort and ensures the change aligns with the project direction before you invest time in it.

## Submitting a PR

- Keep changes focused — one concern per PR
- Include a clear description of what the change does and why
- If fixing a bug, describe how to reproduce it
- If adding a feature, update `config.yaml.example` and `README.md` as appropriate
- Ensure existing tests pass and add tests for new behaviour where relevant

## Security issues

Please do not open a public issue for security vulnerabilities. See [SECURITY.md](SECURITY.md).
