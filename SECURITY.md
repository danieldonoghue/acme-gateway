# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, use GitHub's private vulnerability reporting feature:

1. Go to the [Security tab](../../security) of this repository
2. Click **"Report a vulnerability"**
3. Fill in the details of the issue

You can expect an acknowledgement within 48 hours and a resolution or update within 14 days depending on severity.

Please include as much of the following as possible:

- A description of the vulnerability and its potential impact
- Steps to reproduce or a proof of concept
- Any suggested mitigations if you have them

All valid reports are appreciated. If the vulnerability is confirmed, you will be credited in the release notes unless you prefer to remain anonymous.
